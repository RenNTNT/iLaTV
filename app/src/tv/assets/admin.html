主题色（全局）
暖橙（经典）
背景明暗 · 深色背景
点色块立即切换并保存，首页 WebView、电视版网页后台、手机版设置页三处一起换色。
只改变强调色 / 按钮 / 选中态 / 高亮 / 链接，浅色底与排版结构保持不变；默认「暖橙（经典）」就是历版配色。
配置存各自设备本机，电视版与手机版互不同步；换包名迁移时随数据备份一起导出。
背景明暗：选「亮色」后首页与手机版设置页改为白底深字，5 套主题色都能叠用； 电视版网页后台本来就是浅色，保持不变。
启动页
设为「影视分类」后，打开软件直接进入影视分类页，顶部可直接点播搜索，按返回键回首页。
设为「IPTV 直播」后，打开软件直接进入上次观看的频道，按返回键回首页。
电视端「功能菜单 → 启动设置」也能改这一项，两边实时同步；改动在下次打开软件生效。
应用模式
桌面应用：iLaTV 会成为系统可选桌面，按 Home 键回到 iLaTV 首页，桌面图标仍保留。
保存后点下方按钮，在电视上选择 iLaTV 并勾「始终」；没设为默认时按 Home 会弹选择框。
切回「普通应用」即可取消 HOME 能力；若系统已记住默认桌面，需要重新选一次。
桌面应用模式仅电视版生效：手机版保留开关与配置，但不会替换手机系统桌面。
开机自启动
开启后开机自动进入 iLaTV，启动页设置（首页 / 影视分类 / IPTV 直播）照常生效。
设为「桌面应用」时开机由系统直接启动，最可靠；普通应用模式在部分 Android 10+ 设备 可能被系统后台启动限制拦下，需把 iLaTV 加入系统「自启动管理 / 电池优化白名单」。
安装后至少要手动打开过一次 App，否则系统不会给该应用发开机广播。
设备系统解码能力
只读
正在读取电视端解码器…
这里列出电视系统 MediaCodec 实际提供的视频解码器。硬解列表里没有的编码， 「自动选择」在解码失败时会自动切到系统解码并尝试软解兜底。
清除电视缓存
本机
清除电视端的播放进度、「继续观看」记录和图片等网络缓存；
不会影响片源列表和跳过片头片尾等设置。
数据备份 / 换包名迁移
JSON
导出会下载一份 JSON，包含片源、直播订阅、频道与点播收藏、观看记录、启动页、解码方式与画面比例、SMB 网盘等全部设置。
换新包名的版本时：先在旧版导出 → 卸载旧版 → 装新版 → 在这里导入 → 重启 App 即可全部恢复。
备份文件包含 SMB 网盘密码，请妥善保管、不要随意外发。
点播播放引擎
只影响影视点播。
「自动选择」：先用内置 ExoPlayer 播，遇到解码失败自动切换到系统解码重试， 从刚才的进度续播，不用手动换档；仍失败再返回选集。
「内置 ExoPlayer」：只用内置硬解，解码失败不自动切换。
「系统解码」：一上来就显式调用电视系统 MediaCodec 解码器，硬解初始化失败 自动回退软解，适合老设备、花屏或提示「解码失败」的片源。
三档都在应用内播放，保留选集与跳过片头片尾，不会跳出应用。
点播画面比例
只影响影视点播。和电视点播播放器「菜单键 → 画面比例」是同一份设置，两边实时同步。
自适应：片源比例接近屏幕时自动铺满，差得多（如 4:3 老片、宽银幕电影）则完整显示留黑边；
原始比例：恒按片源自身比例完整显示（默认）；全屏显示：恒保持比例裁剪铺满、无黑边。画面始终不变形。
过滤成人分类
已开启
开启后，影视分类与搜索结果里会过滤掉成人分类；关闭则按片源原样展示。
与电视端共用同一份配置，保存后立即生效。
跳过片头 / 片尾
跳过片头：每集开始自动跳到第 N 秒。
跳过片尾：片尾剩余 N 秒时自动播下一集。
填 0 表示不跳过。
边框与字体大小
50~200%
边框大小100%
字体大小100%
「边框大小」同时作用于三处选台界面：全屏直播时左侧滑出的选台抽屉、独立的全屏选台页、首页 WebView 里的网页直播页两栏；框宽、行高、台号徽章与分组名 / 频道名 / 台号等框内字体按同一百分比缩放。
「字体大小」独立控制右缘「节目单 ›」点开的频道信息面板文字，以及网页直播页的节目单按钮，互不影响。
默认 100% 就是历版原样。设置随数据备份一起导出。
直播解码
只影响 IPTV 直播，与点播播放引擎分开记忆，改一边不动另一边。
这里和电视端「功能菜单 → 解码方式」是同一份设置，两边改完实时同步； 在后台改完，正在播放的直播会立即按新档重建，不用退出重进。
直播画面比例
只影响 IPTV 直播，与点播画面比例分开记忆，改一边不动另一边。
和电视端「功能菜单 → 画面比例」是同一份设置，两边改完实时同步；在后台改完， 正在播放的直播会立即按新比例重排，不用退出重进。
自适应 / 原始比例 / 全屏显示三档含义与点播相同，默认「原始比例」，画面始终不变形。
换台反转
只反转 IPTV 直播全屏播放时 ↑↓ / 频道± / 媒体前后键的换台方向。
选台界面的 ↑↓←→ 一律按原始方向，不反转；←→ 切线路、数字直选、OK 播放也不受影响。
和电视端「功能菜单 → 换台反转」是同一份设置，两边改完实时同步，保存后立即生效。
分组管理
显示 / 隐藏
隐藏的分组不会出现在 IPTV 直播的选台列表，也不参与 ↑↓ / 频道± 换台；
频道缓存始终保留全量，重新显示即可恢复。收藏夹与直播推送搜索不受影响。
改完点「保存分组设置」，返回 IPTV 直播页即生效。
